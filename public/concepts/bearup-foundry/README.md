# BEARUP — «Мастерская»

Изолированный интерактивный макет главной. Не импортирует игровые JS-бандлы,
не вызывает API, не читает аккаунт и не проводит платежи. Все цифры и названия
в app.js — дизайн-примеры. Существующие изображения и токены темы используются
как локальные ресурсы. Главная страница и боевые маршруты не изменены.

Адрес на локальном статическом сервере:
http://127.0.0.1:3102/concepts/bearup-foundry/

Запуск из D:/NewCasesRust:

```powershell
node -e 'const express=require("express");const app=express();app.use(express.static("public"));app.listen(3102,"127.0.0.1")'
```

В макете работают поиск, сортировка, фильтры серий, избранное в памяти страницы,
карточки с описанием, переключение ступеней наград и демовкладки батлов.
Пополнение, профиль и игровые режимы показывают пояснение, а не выполняют действие.
Предметы в ленте обозначены существующими иллюстрациями кейсов; при реализации
лента должна получать реальные предметы из API.

Проверено в браузере: фильтр старта (3 карточки), поиск «Холодный» (1 карточка),
две вкладки батлов, наличие всех изображений; на ширине 390 px нет
горизонтального переполнения. Это предложение дизайна, не готовая замена SPA.
