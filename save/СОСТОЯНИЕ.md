## Что было сделано

### Инфраструктура

- **Steam-авторизация** (OpenID 2.0) — [services/auth.js](../services/auth.js). JWT на `crypto`, refresh в httpOnly-cookie, allowlist для `redirect_to`.
- **Вход по e-mail** — [services/emailAuth.js](../services/emailAuth.js). Пароли `scrypt`, подтверждение, сброс. Ответы на «нет пользователя» и «неверный пароль» одинаковые, чтобы почту нельзя было перебирать.
- **Passkey-вход в админку** (WebAuthn) — [passkeys.js](../admin.titanrust.ru/server/passkeys.js). Первый ключ без приглашения, дальше `ADMIN_INVITE_CODE`.
- **Отправка писем** — [services/mailer.js](../services/mailer.js). Настоящий SMTP при заданном `SMTP_HOST`, иначе вывод в лог. Тракт проверен локальным приёмником: письмо дошло, код внутри тела.

### Каталог

- **5434 предмета** из Steam Market — [services/steamCatalog.js](../services/steamCatalog.js). Фоновый обход, возобновляемый после рестарта, круг ~27 минут.
- Редкость берётся из `name_color`, а не из цены. Цены конвертируются USD → ₽ по живому курсу.

### Игровая математика

- **Взвешенный розыгрыш** — [services/drops.js](../services/drops.js). Веса из `ticketRange` → `chance` → расчёта по RTP. Показанные шансы равны разыгрываемым.
- **Апгрейдер**: `chance = ставка / цель × RTP`. Проверено по 1500 игр на множитель.
- **Баттлы** — [services/battles.js](../services/battles.js). Состояние в SQLite, банк победителю.
- **Розыгрыши** — [services/giveaways.js](../services/giveaways.js). Победитель честным броском, приз на баланс.
- **Инвентарь** — [services/inventory.js](../services/inventory.js). Предмет вместо денег, продажа, заявка на вывод скинов.
- **Provably fair с фиксацией до игры** — [services/fairness.js](../services/fairness.js). Публикуется только `sha256(serverSeed)`.
- **Защита от убыточных кейсов** — [services/caseHealth.js](../services/caseHealth.js). Открытие блокируется при отдаче выше `CASE_MAX_RTP`.

### Админка

- 20 недостающих таблиц, универсальная фабрика CRUD — [adminRoutes.js](../admin.titanrust.ru/server/adminRoutes.js), [adminSchema.js](../admin.titanrust.ru/server/adminSchema.js).
- Сводки по деньгам и RTP считаются из реальных транзакций.
- **Связка админка → сайт**: сайт читает те же таблицы. Выключенный в админке режим гаснет на сайте.

- **RTP кейсов** — заявлено 95%, по 136 фактическим открытиям получилось 93.9%, частоты совпали с показанными шансами.
- **Апгрейдер** — x2: заявлено 47.50%, факт 45.73%; x4: 23.75% / 24.27%; x5: 19.00% / 21.13%.

- **Инвентарь** — 5 кейсов дали 5 предметов, продажа вернула деньги, заявка заблокировала 2 из 4, отмена вернула все 4.
- **Промокоды** — фантомный код отбивается, лимит и повторное применение работают.
- **Баланс** — переживает перезапуск сервера (проверено на 7777 ₽).
- **Админка** — 17 разделов проходят создание → изменение → удаление, 8 кнопок-действий, 8 экранов настроек.

## Исправленные баги, которых никто не искал

1. **Вечный спиннер на всех маршрутах.** `?v=2002` на entry-скрипте расщеплял ES-модуль на две копии, приложение монтировалось дважды, Vue уходил в бесконечный цикл в `removeFragment`.
2. **`attachAuth` регистрировался ниже игровых роутов** — `/cases/open`, апгрейдер, баттлы и инвентарь не видели токен и работали как гость.
3. **Промокод принимался любой** — `TESTCODE` давал +250 ₽.
4. **Цены занижены в ~83 раза** — Steam отдаёт USD, а код писал их как рубли.
5. **Редкость определялась по цене** — диапазоны цветов перекрываются почти полностью.
6. **13 связей `case_items`** вели на удалённые предметы; два кейса имели отдачу 3086%.
7. **Дедлок на 401** в `/user` — обработчик в бандле заканчивается промисом, который не резолвится никогда.
8. **4330 предметов ошибочно скрыты** — сравнение дат разных форматов.
9. **За отклонённое открытие списывались деньги** — проверка шла после списания.
