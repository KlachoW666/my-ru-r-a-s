# save/ — снимок для продолжения работы

Папка нужна, чтобы после очистки контекста можно было продолжить с любого места, ничего не выясняя заново.

| Файл | Зачем |

| [ПРОДОЛЖИТЬ.md](ПРОДОЛЖИТЬ.md) | что осталось, в каком порядке брать, как запустить |
| [ЛОВУШКИ.md](ЛОВУШКИ.md) | грабли этого проекта — самое ценное из накопленного |

Техническая документация лежит отдельно, в [../docs/](../docs/) — 10 файлов. Здесь только состояние работы, а не описание системы.

## Как начать новую сессию

Достаточно одной фразы:

> Прочитай `D:\NewCasesRust\save\` и продолжи.

Остальная документация подключается по ссылкам из этих файлов.
