# Что осталось и как продолжить

## Запуск

```bash
cd D:/NewCasesRust && npm start
```

```bash
cd D:/NewCasesRust && npm run admin
```

Сайт — http://localhost:3101, админка — http://localhost:8080. Серверы независимы, поднимаются по отдельности.

Локальная разработка без реального Steam-логина:

```bash
cd D:/NewCasesRust && NODE_ENV= PUBLIC_URL=http://localhost:3101 ALLOW_MOCK_AUTH=1 npm start
```

Проверить, что всё живо:

```bash
curl -s http://localhost:3101/api/v1/cases/health
```

## Осталось, по приоритету

### 1. Включить защиту админки — единственное реально опасное

`ADMIN_REQUIRE_AUTH=0`: админка **пускает любой запрос без токена**. Passkey не зарегистрирован ни один, поэтому просто поставить `1` нельзя — потеряется доступ.

Порядок:

1. В `.env` поставить `ADMIN_RP_ID=localhost` (RP ID обязан совпадать с доменом в адресной строке).
2. Открыть http://localhost:8080/login.html и зарегистрировать ключ.
3. Проверить: `curl -s http://localhost:8080/api/v1/admin/auth/passkeys` — должно быть `count: 1`.
4. Поставить `ADMIN_REQUIRE_AUTH=1`, перезапустить админку.

Делается за один заход и не зависит ни от чего внешнего.

### 2. Ролевая модель админов

Любой admin-токен может всё. В `admin_users.role` роль есть, сервер её не использует. Нужны проверки в `requireAdminJWT` и разбиение разделов по правам.

### 3. Steam-бот для вывода скинов

Упирается в ваши учётные данные. Нужен отдельный аккаунт с торговой сессией (`steam-user` + `steam-tradeoffer-manager`), тогда заработают:

- отправка трейд-оффера по заявке (сейчас заявка создаётся и ждёт ручной обработки в админке);
- пополнение скинами — `GET /wallet/skins/inventory` сейчас честно отдаёт 501.

### 4. SMTP на проде

Заполнить `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS` в `.env`. Код менять не нужно — тракт проверен, при пустом `SMTP_HOST` коды просто пишутся в лог.

### 5. Приватные баттлы

Флаг `is_private` сохраняется, проверки доступа по ссылке нет.

### 6. Гонки — на сервере не решаются

Раздела нет ни в одном чанке бандла и нет маршрута в роутере. Нужна более новая сборка фронта. Проверить:

```bash
grep -rl "Гонки" D:/NewCasesRust/public/assets/js/
```

## Обязательно к перевыпуску

**Ключ Steam Web API** лежал в репозитории открытым текстом и остался в истории git. Сейчас читается из `.env`, но старое значение скомпрометировано — перевыпустить на https://steamcommunity.com/dev/apikey

## Особенности окружения

- **Исходников Vue нет** — `public/assets/` это собранный бандл. Правка в нём работает, но затрётся при пересборке. Уже внесены две: адрес WebSocket в `index-CBN0naXL.js` (бэкап `.bak`) и убранный `?v=2002` из `index.html` (бэкап `index.html.bak`).
- **`node_modules` больше не в git.** При слиянии веток они могут исчезнуть с диска — тогда `npm install` в корне и в `admin.titanrust.ru/server`.
- **База одна** — `admin.titanrust.ru/server/database.sqlite`. Перед ручными `UPDATE`/`DELETE` останавливать серверы, иначе `SQLITE_BUSY` и блокировка файла при операциях git.
- **Граф знаний** — `graphify query "<вопрос>"` из корня проекта. После правок: `graphify update .`
