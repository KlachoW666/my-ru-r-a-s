# Bear branding assets

- `bear-logo-96.png` — исходная лаймовая эмблема медведя, 96×96 px.
- `bear-paw-currency-128.png` — исходная лаймовая валюта-лапа, 128×128 px.
- `bear-logo-orange-96.png` — рабочая оранжевая эмблема, 96×96 px.
- `bear-paw-orange-128.png` — рабочая оранжевая валюта-лапа, 128×128 px.
- `bear-logo-orange-master.png` и `bear-paw-orange-master.png` — варианты, созданные генератором изображений.
- `bear-gunsmith-banner-1470x630.png` — готовый широкий баннер с медведем-оружейником.
- `bear-gunsmith-banner-master.png` — мастер-версия баннера от генератора.

Все файлы имеют прозрачный фон. В интерфейсе используются оранжевые версии из `public/image`.
