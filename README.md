# NewCasesRust — Kaban.gg Web Application

Готовый к запуску проект платформы открытия кейсов Rust (**Kaban.gg**).

## 📁 Структура проекта
```text
D:\NewCasesRust\
├── package.json          # Зависимости и скрипты запуска
├── server.js              # Веб-сервер Express, API-моки, статическая отдача и SPA-роутинг
├── README.md              # Документация по проекту
└── public/                # Готовые клиентские файлы
    ├── index.html         # Основная HTML точка входа
    ├── assets/            # CSS стили, JS бандлы, WebP/PNG иллюстрации
    ├── audio/             # Звуковые эффекты (.mp3, .ogg, .wav)
    ├── avatars/           # Аватары пользователей Steam
    ├── icons/             # PWA иконки приложения
    ├── image/             # Баннеры и фоны
    ├── packs/             # Скрипты виджетов
    ├── png/               # Иконки и логотипы
    └── svg/               # Векторная графика
```

## 🚀 Запуск проекта

### 1. Установка зависимостей:
В терминале перейдите в папку проекта и выполните:
```bash
cd D:\NewCasesRust
npm install
```

### 2. Запуск сервера:
```bash
npm start
```

### 3. Открытие в браузере:
Перейдите по адресу: **[http://localhost:3030](http://localhost:3030)**

## ✨ Реализованный функционал
- **Клиентский роутинг (SPA)**: Автоматическая обработка маршрутов `/crate-pvp`, `/upgrader`, `/giveaway`, `/cases/:slug`, `/profile`.
- **Интерактивные баннеры**: Видео-циклы mp4/webm и промокодный блок.
- **Звуковое сопровождение**: Воспроизведение звуков открытия кейса, рулетки, баттлов и выигрышей.
- **Mock API (`/api/v1/*`)**: Автономная работа без ошибок сети.
