# Ребрендинг SATCHEL

Перевод игрового сайта из айдентики TITAN RUST в бренд **SATCHEL / satchel.top**.
Админка не затрагивалась — это независимая дизайн-система.

## Режим реализации: B

Исходников Vue в репозитории нет. В `public/` лежит собранный Vite-бандл:
минифицированные чанки `assets/js/*.js`, извлечённые `assets/css/*.css` и
точка входа `index.html`. Ни `src/`, ни `.vue`, ни `vite.config.*` — проверено
поиском по всему дереву и по веткам.

Поэтому вместо редизайна в исходниках сделан **слой ребрендинга поверх сборки**:

1. один файл темы `public/assets/css/satchel-theme.css`, подключённый последним;
2. замена статических ассетов по прежним путям и с прежними размерами;
3. точечная замена строковых литералов в чанках, каждый файл после правки
   проверен `node --check`;
4. три чанка переписаны целиком — там, где перекраски было мало (логотипы и
   водяные знаки нарисованы контурами прежнего бренда).

## Что нужно перенести на следующую сборку фронта

Пересборка бандла затрёт правки в `assets/js` и `assets/css`. Порядок переноса:

1. Скопировать `public/assets/css/satchel-theme.css` — он самодостаточен.
2. В `index.html` добавить последним:
   `<link rel="stylesheet" href="/assets/css/satchel-theme.css">`
3. Скопировать `public/brand/`, `public/assets/cases/satchel/`,
   `public/favicon.*`, `public/logo-symbol.png`, `public/icons/`,
   `public/apple-touch-icon.png`, `public/og-banner.jpg`,
   `public/assets/header/logo*.webp`, `public/assets/png/coin-*.png`,
   `public/assets/battles/*.png`.
4. Заново прогнать скрипты из `scratchpad`-набора (см. «Как воспроизвести»).

Пункты 1–3 покрывают почти всё. Правки в чанках нужны только потому, что
исходников нет; **как только появятся исходники Vue — правильнее перенести
токены в них и выбросить пункт 4.**

### Цвета

Лайм `#b2ff00` и его семейство — 101 замена в 35 файлах, плюс 4 в URL-кодировке
(`%23B2FF00`) и один блоб base64 в `bottom-bar-*.js`: иконки статистики в
подвале лежат как data-URI, и обычный поиск по hex их не находил.

Голубой `#0af` (второй цвет прежней темы) разведён по ролям: основное
действие — в оранжевый, декоративные панели — в латунь `#c89b62`. Единый тон
на всём интерфейсе убил бы иерархию.

Главный `index-BSsnhUcQ.css` **не правился** — все его токены перекрыты в
`satchel-theme.css`.

## Что намеренно НЕ менялось

### Внутренние идентификаторы

Остаются со старым именем ради совместимости. Это не дефект:

| Идентификатор | Файл | Почему |
|---|---|---|
| `titanrust:wallet:withdrawTab` | `WalletPage-*.js` | ключ localStorage: смена сбросит выбранную вкладку у всех |
| `titanrustFastRoll` | `index-B3loti9-.js` | ключ localStorage: сбросит настройку быстрого прокрута |
| `titanrustBannerMotion` | `motion-pref-*.js` | ключ localStorage: сбросит выбор анимации |
| `titanrust.auth-refresh` | `mutator-*.js` | имя `navigator.locks`; переименование рассинхронизирует обновление сессии между вкладками, открытыми на разных версиях |
| `https://cdn.titanrust.ru` | `resolveImageUrl-*.js` | хост CDN — инфраструктура, а не бренд; смена без переезда CDN убьёт все картинки |
| `init("titanrust")`, `/spine/titanrust1/` | `landing-*.js` | пути Spine-анимации, см. блокеры |
| `footer.statBoars` | локали | ключ перевода; сменилось только значение |
| имена файлов `hog-*`, `boar-*` | ассеты | хешированные пути, на которые ссылаются чанки |

### Регистрационные данные

`I.E. Artem Shits`, налоговый номер `286.1573426`, адрес в Ереване — это
юридические данные, а не бренд. Менять их было бы подлогом.

### Контакт поддержки

`support@titanrust.ru` оставлен с пометкой `TODO_CONFIRM_CONTACT`. Ящик на
satchel.top не подтверждён, а подставить несуществующий адрес хуже: письма
игроков просто пропадут.

### Соцсети

`sameAs` с `t.me/titanrust` и `vk.com/titanrust` **удалён**, а не заменён:
это аккаунты другого бренда, а satchel-аналоги не подтверждены. Неверный
`sameAs` приписывает организации чужие аккаунты.

### Код подтверждения Яндекса

Оставлен с пометкой `TODO_CONFIRM_DOMAIN`: он выдан для titanrust.ru, на
satchel.top бесполезен, но удаление сломает уже пройденное подтверждение,
пока старый домен обслуживается.

### Семантические цвета

Не тронуты и тронуты быть не должны:

- **редкость**: GOLD `#ffc43b`, VIOLET `#a33ee2`, RARE `#65dc04`,
  UNUSUAL `#4076ff`, REGULAR `#756767`. Оранжевый — цвет действия и бренда,
  цвет редкости — информация о предмете. Смешивать нельзя.
- **успех**: `#34c759`, `#87b536` (`--color-btn-success`), `#9fe356`.
- **шкала риска**: низкий зелёный → средний оранжевый → высокий красный.
  Перекрасив низкий в фирменный оранжевый, мы слили бы его со средним.
- **платёжные провайдеры**: `#34a853` (Google), `#017f36` (СБП).

## Как воспроизвести

Скрипты сборки ассетов лежат в scratchpad-наборе и не входят в репозиторий,
кроме двух рабочих инструментов:

- `deploy/import-satchel-cases.js` — подключение артов к кейсам каталога;
- `public/assets/cases/satchel/manifest.json` — пути к артам.

Токены темы — в `public/assets/css/satchel-theme.css`, там же объяснено
каждое переопределение.
