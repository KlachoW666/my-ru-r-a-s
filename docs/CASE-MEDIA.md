# Анимированная обложка кейса

В форме создания и редактирования кейса поле «Обложка кейса» принимает PNG,
JPG, WebP, GIF и MP4 до 10 МиБ. Для MP4 используйте H.264: расширение файла
само по себе не гарантирует поддержку кодека браузером. Перекодирования видео
на сервере нет. Прозрачность обычный MP4 не поддерживает.

Выберите файл через Upload / Replace и нажмите «Сохранить». Для видео доступен
предпросмотр с управлением воспроизведением; Optimize к видео не применяется.
На сайте общий компонент медиа распознаёт MP4, включает повтор без звука и
отключает автозапуск при системной настройке уменьшения анимации.

Используется существующее поле `cases.image`: файл сохраняется в
`public/uploads/cases`, в базе — путь `/uploads/cases/…mp4`. Миграция базы
не нужна. Админка запрашивает локальные загрузки со своего домена, а не со
старого CDN. При ошибке сохранения после успешной загрузки повторная попытка
сохраняет тот же адрес обложки.

Обновление сервера: существующий корневой `update.sh`. Он сохраняет базу,
`.env` и загрузки. После обновления перезагрузите страницу админки.

Правки внесены в собранные Vue-чанки. При появлении исходников перенесите
эту логику в исходные компоненты перед пересборкой.

## Проверка

`node --test tests/case-media.test.js tests/admin-upload-limit.test.js tests/banner-upload-ui.test.js`

Проверяются выбор формата, границы размера, повторное сохранение, отсутствие
оптимизации видео, локальные URL, MP4/PNG-рендеринг, уменьшение анимации,
реальная multipart-загрузка MP4 и ответ `206 video/mp4` на Range-запрос.
HTTP-тесты используют временный каталог, не рабочую базу и не боевые загрузки.
