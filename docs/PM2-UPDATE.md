# Обновление bearz.top

Для установки через `install.sh` используйте корневой `update.sh`:

```bash
sudo bash /var/www/bearz/update.sh
```

Если файл ещё не установлен, скачайте его отдельно от рабочего дерева и запустите:

```bash
sudo curl -fSL https://raw.githubusercontent.com/KlachoW666/my-ru-r-a-s/main/update.sh -o /var/www/bearz-update.sh
sudo chmod 644 /var/www/bearz-update.sh
sudo bash /var/www/bearz-update.sh
```

Скрипт рассчитан на Debian, пользователя — владельца каталога проекта, процессы
PM2 `main-site` и `admin-panel`. Root автоматически передаёт выполнение владельцу.
Другой путь: `--app /путь/к/проекту`. `--dry-run` выполняет проверки и `git fetch`,
но не меняет рабочие файлы и не перезапускает процессы.

Перед остановкой сервисов создаётся SQLite online backup с проверкой `quick_check`
и копия `.env` в закрытом каталоге `backups/update-*`. Затем обновляется только
история `origin/main` через fast-forward. Ручные изменения и разошедшаяся история
блокируют обновление. Изменение рабочей базы, `.env`, загрузок и конфигурации
экземпляра входящим коммитом запрещено. Nginx, сертификаты и API-ключи не меняются.

`npm ci` запускается только при изменении manifest/lock-файлов или отсутствии
node_modules. После этого сначала запускается админка, затем сайт; проверяются
HTTP-ответы, сохраняется список процессов PM2. Есть краткий перерыв в работе.

При ошибке после обновления кода скрипт завершится с ненулевым кодом и укажет
резервную копию и прежний коммит. Автоматического отката кода/базы нет; сервисы
могут остаться остановленными до устранения ошибки. Копии не удаляются автоматически.
Если сбой случился до переключения кода, скрипт пытается запустить старые процессы.

Ключ Steam храните в `/var/www/bearz/.env`, строка `STEAM_API_KEY=...`.
После изменения ключа достаточно `sudo -u bearz pm2 restart main-site --update-env`.
Не присылайте ключ и содержимое `.env` в чат.

Проверки: `node --test tests/pm2-update.test.js tests/deploy-backup.test.js`.
Полный прогон на боевом Debian выполняется владельцем сервера; локально проверены
синтаксис Bash, защита рабочих путей и порядок безопасного обновления.
