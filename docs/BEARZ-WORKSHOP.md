# BEARZ: мастерская

Главная подключает `public/assets/js/bearz-workshop.js` через собранный `index-DoTdMb5b.js`. Стили `public/assets/css/bearz-workshop.css` загружаются после основной темы. При новой сборке Vue нужно перенести эти подключения и правки layout в исходники: изменения собранных файлов могут затереться.

Сохранены каталог, фильтры, промобаннеры и существующие маршруты игр. Лестница получает ступени и прогресс через `useDepositChain`, не создаёт собственных начислений. Карточки ведут на страницы назначенных кейсов. Сворачивание действует до перезагрузки страницы.

Промокод перенесён из нижней части главной в общий верхний блок с героем (`bz-welcome`). Используется прежний компонент PromoCode с его авторизацией, активацией и ошибками. Пустые записи баннеров без текста, медиа, фона и кнопки отфильтрованы; заполненные баннеры и обработчик применения их промокода сохранены. На телефоне поля расположены вертикально.

Для горизонтальной live-ленты отключены старые desktop-эффекты: боковое свечение, нижняя затемняющая маска и hover-слой. Цвета редкостей сохраняются. У лестницы отдельные карточки ступеней; готовое состояние не показывает бессмысленное «0 / 0».

Ссылки сообщества: https://t.me/bearztop и https://vk.com/bearztop. `services/publicSocials.js` заменяет известные старые seed-ссылки при выдаче и сохраняет пользовательские ссылки админки. Изменение серверной выдачи требует перезапуска сервера. Реквизиты владельца нужно отдельно получить у владельца сайта.
